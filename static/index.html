        System RAM caching
        
    
        Keep a component's weights in system RAM between operations (faster; models on an HDD take minutes to re-read). Unchecked = released from RAM after each use.
        
    
        
      
      
      
    
        

    
        Style analysis — vision model
        
    
        Style analysis runs a local vision model through llama-server (llama.cpp). It is started for each
      job and stopped afterwards; while it runs, image generation waits. Nothing is downloaded: give the paths to your
      llama-server.exe, a vision-capable model .gguf and its matching mmproj projector.
      Or set an endpoint URL to use a server that is already running (LM Studio, Ollama…); then no process is started.
